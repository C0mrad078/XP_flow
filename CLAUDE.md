# CLAUDE.md

Project-level instructions for Claude Code when working in this repository.

## Git commit attribution

When creating Git commits:

- Always use the existing Git `user.name` and `user.email`.
- Never add Claude, Anthropic, or any AI assistant as an author or co-author.
- Never add `Co-Authored-By` trailers for AI assistants.
- Do not mention Claude, Anthropic, AI assistance, or AI-generated code in commit messages.
- Commit messages must describe only the actual technical changes.
